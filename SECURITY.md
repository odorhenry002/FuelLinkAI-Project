# Security Policy

## Supported Versions

The project is currently in active development. Security updates are prioritized for the latest main branch.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities publicly.

Instead, report them privately by contacting the maintainer at:

- odorhenry64@gmail.com

Please include:

- a description of the issue
- affected files or endpoints
- reproduction steps
- severity assessment
- any suggested remediation

We will acknowledge the report within 5 business days and work toward a fix as quickly as possible.

## Security Expectations

- Do not commit secrets or credentials.
- Use environment variables for local configuration.
- Review dependency updates regularly.
- Keep CI and CodeQL scanning enabled.
